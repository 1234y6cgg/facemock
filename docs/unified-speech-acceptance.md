# 统一讯飞语音与交付范围调整

日期：2026-10-03。完整模拟面试与八股单题语音统一使用科大讯飞 IAT；当前 `coding` 应用已更新。

## 用户流程与实现

- 移除完整模拟面试的 `SpeechRecognition` / `webkitSpeechRecognition`。浏览器只负责采集音频，识别由后端现有讯飞 WebSocket 适配完成。
- 录音 → 回听 → 上传 → 讯飞转写 → 核对修订 → 确认提交。停止录音及转写成功均不自动发送回答；确认后进入原模拟面试的追问流程。
- 两个入口共用讯飞凭证、16kHz 单声道 WAV、最长 180 秒、50 秒分段、首次加两次手动重试、30 天默认保留及到期清理。
- 模拟录音以 `interview:<id>` 隔离，按消息数量绑定当时的问题。已结束面试、过时问题与相同标识不同音频均拒绝上传或重试；八股录音不能被模拟面试删除误清理。
- 停止后的草稿保存在当前浏览器，上传任务及修订文本可刷新恢复。删除面试会删除后端关联原音与转写任务；清理当前浏览器及其他浏览器中的未上传草稿仍需清除相应浏览器数据。
- 模拟面试确认文字沿用原回答接口，不新建八股练习或 P2 评估。提交后的文字保存在面试消息中。

前端 TypeScript 与生产构建通过，3 项音频格式/权限错误/录制上限检查通过。隔离页面使用公开合成 WAV 和明确标注的本地转写替身，验证未配置时文字仍可用、导入回听入口、失败重试、刷新保留修订文本、确认后仅提交一次修订回答并进入下一题。390×844 视口无横向溢出，控制台错误为 0。
