# FaceMock · Java 后端面试训练器

用自己的话练八股和项目表达，查看逐项反馈与材料原文，再答一次对比；也可以围绕自己的简历完成整场模拟面试，回看对话与复盘报告。

## 快速开始

项目目录为 `facemock`；Docker Compose 项目为 `facemock`，应用镜像为 `facemock-app:latest`。已有部署的改名和数据迁移说明见 [目录及 Docker 改名记录](docs/facemock-rename.md)。

1. 准备环境配置：

```bash
cp .env.example .env
# 模型 Key 可留空，启动后在网页填写；按需调整数据库和端口
```

2. 一键启动：

```bash
docker compose up -d --build
```

3. 打开浏览器访问 <http://localhost:8080>，先点击左下角齿轮“设置”，选择服务商并填写自己的 API Key，可测试连接后保存，无需重启。首页“今日练习”给出到期复习、薄弱点和新题推荐；也可以自主选题，或在“项目话术”核对简历项目事实后练习。完整模拟入口为 `/mock`。

## 功能介绍

### 八股专项练习

内置 **180 道 Java 后端面试题、18 类主题、540 个评分知识点**，覆盖 Java 基础、集合、IO、并发、JVM、Spring、MyBatis、MySQL、Redis、Kafka、消息队列、网络、操作系统、数据结构与算法、分布式、系统设计、安全和工程实践。

- 按主题、难度筛选或搜索题目，用自己的话作答。
- 逐项查看正确、部分、缺失、错误及无法判断的知识点，结合回答原话定位问题。
- 查看参考解析、常见误区和来源资料，再答一次对比前后变化，并通过专项追问练习薄弱点。

### 项目话术训练

从简历中选择项目，整理可编辑的项目事实卡和参考材料，练习两分钟介绍、个人职责、技术选型、困难定位、效果证明和复盘改进六类表达。

- 反馈关联项目材料与原文出处，方便核对自己的表达。
- 缺少的事实由本人补充，材料冲突展示双方原文。
- 每个项目使用独立检索范围；保留回答与材料快照，支持重答对比和专项追问。

### 简历驱动的模拟面试

上传 PDF 或 Word 简历，填写目标岗位与岗位要求，围绕个人经历完成一场模拟面试。

- 多 Agent 协作，从背景、方案、细节、难点逐步追问到权衡与扩展。
- 根据回答质量调整难度，结合压力面和场景设计题练习临场表达。
- 回答后获得即时点评，结束后查看多维复盘、薄弱点与改进建议；面试记录支持回看与断点续面。

### 语音练习

八股单题训练和完整模拟面试统一接入 **科大讯飞 IAT**，支持最长 180 秒录音。

- 停止录音后先回放，再转写；核对或修订文本后提交回答。
- 保留原音与原始转写，单题练习提供回答时长和表达建议。
- 转写失败可重试；原音默认保留 30 天，也可主动删除。使用前需配置讯飞凭证，见 [语音使用说明](docs/speech.md)。

### 薄弱点复习与进步记录

首页汇总到期复习、薄弱点和新题推荐，把一次练习衔接到后续复习。

- 默认按 1 / 3 / 7 天安排延迟复测，支持调整时区和复习间隔、跳过或暂停。
- 区分独立回答与有辅助回答，两次到期无辅助通过才计为已巩固。
- 通过练习历史、知识点状态和进步记录回看变化，进度保存在 MySQL 中。

### 自带模型 Key

点击左下角“设置”即可选择模型服务并填写自己的 API Key，支持连接测试、加密保存和即时切换，无需重启应用。

内置 **DeepSeek、通义千问、豆包、GLM、Kimi、MiniMax** 预设，也支持自定义兼容接口。语音识别单独配置讯飞凭证，详见 [模型设置说明](docs/model-settings.md)。

### 记录管理与数据导出

保存每次回答和评估版本，支持刷新恢复、失败重试、练习删除和 JSON 个人数据导出。题目或项目材料更新后，历史练习保留当时的评估依据；导出包含文字与记录，录音文件需单独备份。

## 推荐使用流程

1. **配置模型**：在设置中选择服务商，填入自己的 Key 并测试连接。
2. **练八股**：从题库选择一个主题，独立回答后查看反馈，再答一次巩固表达。
3. **练项目**：上传简历，确认项目事实卡，练习项目介绍和技术决策的讲述。
4. **做模拟与复习**：完成整场模拟后查看复盘，并按首页的到期安排复测薄弱知识点。

## 技术栈

Spring Boot · LangChain4j · 国内模型兼容接口 · Apache Tika · MySQL · Redis · ChromaDB · React + Vite + TypeScript · Docker Compose

## 技术知识库 RAG

使用本地中文 BGE 模型生成 512 维向量，接入 ChromaDB v2，支持带来源的知识导入、语义检索、版本更新和重复导入去重。启动时自动导入 10 篇基础知识卡，追问、压力面、场景题和回答评估均使用检索参考。

查看状态：`GET /api/knowledge/status`；检索：`GET /api/knowledge/search?query=...`；导入文本或 Markdown：`POST /api/knowledge/documents`。

配置、请求示例、持久化与测试说明见 [RAG 使用说明](docs/rag.md)。
